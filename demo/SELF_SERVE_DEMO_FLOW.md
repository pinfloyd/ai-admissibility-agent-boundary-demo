# Self-Serve Demo Flow

Principle: no registration before value.

Flow:
1. User enters a company name or chooses a sample.
2. Agent runs read-only signal discovery.
3. Agent creates a local signal brief.
4. Agent creates draft-only text.
5. UI shows hard blocks: email sent = NO, outreach = NO, external action = NO.
6. Paid mode later requires token plus external boundary ALLOW.
