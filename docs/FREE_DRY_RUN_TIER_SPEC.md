# Free Dry-Run Tier Spec

Free tier is read-only and local-only.

Allowed:
- public signal discovery
- local scoring
- local brief generation
- draft-only text generation

Forbidden:
- Gmail draft creation
- email send
- outreach
- external action
- production execution

Hard status: EMAIL_SENT=NO, OUTREACH_DONE=NO, EXTERNAL_ACTION_DONE=NO.
